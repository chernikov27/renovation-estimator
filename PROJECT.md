# Renovation Estimator

Веб-сервис расчёта строительной сметы по отделочным работам: пользователь
загружает фото объекта, вводит размеры комнат, выбирает работы (шпаклёвка,
грунтовка, покраска) и получает смету с PDF-экспортом и share-ссылкой.

## Статус

Проектирование завершено, реализация не начата.

- Дизайн: `docs/superpowers/specs/2026-06-11-renovation-estimator-mvp-design.md`
- ТЗ для Codex: `docs/CODEX_REQUIREMENTS.md`
- Сид прайса: `data/price_list.seed.json`

## Scope MVP

- Мастер из 2 шагов: объект + фото (jpeg/png/webp) → комнаты, проёмы, работы.
- Несколько комнат в одной смете.
- Расчёт работ и материалов по сид-прайсу; цена работы правится инлайн в смете
  (снапшоты цен — правка прайса не меняет старые сметы).
- Итог с TVA/НДС (%).
- Печать сметы из браузера (print-CSS), read-only ссылка для клиента.
- Языки RU/FR, валюта EUR, без регистрации.

## Стек

React (Vite, TypeScript) · FastAPI (Python) · SQLite (`create_all` + сид, без миграций).

## Roadmap

- **Фаза 1 (MVP)** — см. Scope выше.
- **Фаза 2** — серверный PDF, экран редактирования прайс-листа, Alembic-миграции,
  HEIC-фото, наценка/накладные (markup_pct) и статусы смет, правка норм расхода
  в форме, AI-анализ фото (состояние стен → рекомендации работ и слоёв).
- **Фаза 3** — Excel-экспорт, регистрация и список смет, региональные прайсы,
  мультивалютность, PWA, шаблоны смет, каталоги материалов.
